Markdown Reader

Màn hình đầu tiên dùng để duyệt cây thư mục và chọn file Markdown trước khi chuyển sang trang đọc.

Repo hiện tại

Duyệt cây thư mục rồi bấm vào file `.md` để mở màn hình đọc.

Trang này chỉ đọc các file Markdown thuộc đúng repo GitHub hiện tại.
